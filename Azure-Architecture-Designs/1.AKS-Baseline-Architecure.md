
# Scenario-1: AKS BASELINE ARCHITECTURE
## Requirements:
* Baseline architecture for deploying Azure Kubernetes Service (AKS) cluster securely.
* Focus on AKS cluster infrastructure, not specific workload implementation details.
* Integrates Azure services for observability, security, and multi-regional scalability.
* Uses hub-and-spoke network topology for isolation and governance principles.
* Implements Azure Firewall, Bastion, and VPN gateway in hub network.
* Spoke network hosts AKS cluster, ingress resources, and private endpoints securely.
* Recommends Azure CNI Overlay for efficient IP address space management.
* Enforces identity integration using Microsoft Entra ID and managed identities.
* Secures ingress traffic with TLS termination and Web Application Firewall.
* Suggests autoscaling for pods and nodes to ensure workload reliability.
